1. Trigger Nodes (The starting Point)

Triggers in automation : 
--> Starts the workflow whenever something happens.
--> It waits for events like new emails, form submissions, or file uploads.
--> It can be scheduled to morning (8AM), evening, or any particular time.

2. App/Core nodes (Logic & Handling)

--> IT filter, modify, tranform, change the data before passing it forward.
--> Filter Node -> Checks if the data meets certain conditions.
--> Set Nodes --> Add ot modifies data.
--> COde Node -> Used to write python, Js or any language code.
--> Webhook Node --> Listens or incoming data.
--> AI Node -> Generate text or process data using LLMs.


3. Action Nodes (Final Steps)

--> Send data to external apps or complete specific actions.

Examples : 
1. Google Sheets Node --> Updates a spreadsheet.
2. Slack Node --> sends notifications.
3. Email Node --> Sends automated responses.
4. Database node --> Send or update data in database.
